# Cryptocurrency Social Media Campaigns Analysis

Analysis of Coordinated Cryptocurrency-Related Social Media Campaigns using the bounty events dataset from BitcoinTalk.

## Overview

This project analyzes a comprehensive dataset of coordinated crypto bounty events and their associated social media campaigns. The dataset includes:

- **15.8K** cross-media bounty events
- **185K** participants
- **10M** forum comments
- **82M** social media URLs

The data was collected from the Bounties(Altcoins) subforum of the BitcoinTalk online forum from May 2014 to December 2022.

## Motivation

The rise in cryptocurrency adoption has brought many new and inexperienced investors to the crypto space. These investors are often disproportionally influenced by information from social media. This dataset enables research into how coordinated bounty events create artificial "hype" around crypto projects to influence token prices and market dynamics.

## Dataset Source

**Paper:** "Coordinated Cryptocurrency-Related Social Media Campaigns"  
**DOI:** https://doi.org/10.1609/icwsm.v17i1.22219  
**Venue:** ICWSM 2023 (International Conference on Web and Social Media)

## Getting Started

### Prerequisites

- Python 3.8+
- Jupyter Notebook
- pandas, numpy, matplotlib, seaborn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/rcrtss/upf-ddsa-2026.git
cd upf-ddsa-2026
```

2. Create a virtual environment (optional):

venv:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

pyenv:
```bash
pyenv virtualenv 3.9 upf-ddsa-2026
pyenv activate upf-ddsa-2026
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```
